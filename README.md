# 出動！重組句子搬運員！！

小三中文「重組句子倉庫番」Three.js 遊戲，共 15 題。

## 網上遊玩

GitHub Pages：https://aoisoraau.github.io/pth/

## 內容

- 四種難度：幫幫我、想一想、自己來、計時賽
- 15 句關聯詞及疑問句練習
- 推箱、拉箱、鎖定正確答案、復原及重設
- 計分、限時加分、三星及五星完成回饋
- 鍵盤、iPad／iPhone 觸控方向鍵及 Xbox 手掣
- 8-bit 背景音樂、操作音效及完成句子朗讀

網站版使用 jsDelivr 載入 Three.js 0.160.1 及 jf open 粉圓網頁字型；授權資料見儲存庫內的授權檔案。
